# Creo 原生特征建模

适用于规则零件及需要在 Creo 中编辑尺寸的特征树。复杂放样或自由外形应选择几何生成与 STEP 导入通道；用户指定通道时遵循用户选择。

## 前提

本技能依赖独立安装的 Creo MCP 后端及配套 TOOLKIT 插件，不包含后端、DLL 或 PTC SDK。先确认当前工具列表提供下述接口，且部署版本支持所需 action。输出目录、模板和模型名前缀由后端配置决定，使用返回值识别实际模型。

Creo 应处于可交互状态，并能明确定位唯一目标会话。不要为建模关闭其他会话、终止通信进程或变更启动配置。

## 建模流程

1. 从请求中确定尺寸、单位、特征顺序及输出要求。以下示例单位为毫米。
2. 若已确认后端状态检查不会自动清理进程，调用一次 `creo_native_status`。失败时查看错误，停止特征创建并排查连接或插件状态。
3. 新零件优先使用 `creo_native_design(name, features, save=True)`。它依次新建、建特征、保存；不是失败时自动回滚的事务。
4. 需要分步控制时用 `creo_native_new_part`、`creo_native_feature`、`creo_native_save`。`creo_native_apply` 在当前模型上操作，调用前确认当前目标，避免把新特征加到无关模型。
5. 检查返回的 `ok`、逐项结果及 `failed_index`。失败时保留已完成步骤，只在修正原因后继续；不要原样重放整个设计造成重复特征。
6. 核对再生状态、特征类型及实际几何，确认保存路径存在。报告模型名、关键尺寸、特征 id、真实 `.prt.N` 路径及尚未完成的要求。

具体 action、边选择和完整调用示例见 [references/features.md](references/features.md)。

## 建模判断

- 同平面且同深度的多个轮廓可合并为一个拉伸特征；用户需要独立孔特征或不同设计意图时分别创建。
- 外缘圆角使用明确边选择。`all` 和 `top_outline` 可能包含孔口；`outer` 用于顶面外轮廓。
- 曲面特征可能没有实体 body；需要实体时再加厚，并核验得到闭合实体。
- `body_count >= 1` 或特征创建成功不能单独证明尺寸与拓扑正确。质量属性为空时记录原因，不能据此编造体积或密度。
- 当前参考实现禁用了 `draft` 和 `mirror`，其返回为未实现。不要把工具说明中列出 action 视为已验收能力。
- STEP 导入几何不等同于原生参数化特征树。交付时明确实际通道。
