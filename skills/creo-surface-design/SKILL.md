# Creo 曲面与复杂外形

适用于放样过渡、扭转叶片、扫掠管、弯头和复杂外形。目标是可用的导入几何；用户要求原生特征树时，先明确这条通道的交付形式。

## 前提与输出

依赖独立安装的 Creo MCP 后端和其 build123d 环境。本技能包不包含后端、PTC SDK 或 Creo。先核对实际工具、模板与依赖版本。文件目录和名称以工具返回值为准。

`creo_surface(name, template, params)` 将模板参数转换为 build123d 代码，再导出 STEP、导入 Creo。模板和完整示例见 [references/templates.md](references/templates.md)。

导入的 BRep 是实体或面组，不是 Creo 原生放样、边界混合或样式特征。模板参数表提供重生成入口，不能当成 Creo 内可逐特征编辑的参数化历史。

## 流程

1. 确定包络、截面、路径、壁厚及实体/曲面要求。先验证坐标系和单位，以下示例单位为毫米。
2. 适合现有模板时使用 `creo_surface`。超出模板表达能力时用 `creo_build(code, name)`，将最终几何赋给 `result`；build123d 符号由参考后端预导入。参考实现的建模入口会删除同名旧 `.prt*` 文件；首次设计优先用独立新名，需要替换时先核实目标并备份需保留的版本。
3. 复杂几何先做本地几何校验，再导入：有效性、实体/面组数量、体积、紧包围盒、连通关系。多实体模型是允许的；仅在设计要求单实体时融合。
4. 检查导入及保存结果，确认实际 `.prt.N` 文件、STEP 和参数表路径。工具返回成功不等同于窗口已激活；需要展示时验证实际视图中完整模型可见。
5. 修改模板件时先读 `creo_params(name)`；使用 `creo_regenerate` 前检查同名覆盖行为并保留需要的旧版。修改自定义代码件时重新给代码。

## 几何判断与边界

- 截面顺序和方向应一致，避免扭曲、自交或零厚度。平滑放样、扫掠和加厚都要验证输出拓扑。
- `thicken` 不能自动代表符合要求的中空薄壁件。检查入口/出口是否开放、壁厚和内腔；模板名称不能代替几何验收。
- 保守包围盒可能包住 B-spline 控制网；需要准确尺寸或落地检查时用紧包围盒，例如支持版本的 `bounding_box(optimal=True)`，结合公差解释结果。
- 参考后端没有实现原生 Boundary Blend、ISDX 或 Freestyle 创建。这是当前后端能力边界，不是对所有 Creo 版本或所有 API 的断言。
- Gordon 或 loft 可以提供替代几何，但不保证任意原生特征的连续性、参数或设计意图等价。
