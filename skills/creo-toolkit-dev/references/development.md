# 后端项目开发参考

以下名称描述原始参考项目的布局。取得其他实现时按实际文件调整，不应在本技能仓库中寻找这些文件。

| 后端相对位置 | 用途 |
|---|---|
| `src/agent_bridge.cpp` | 导出函数与参数桥接 |
| `src/features.cpp` | 基础特征及 action 分派 |
| `src/features_a4.inc` | 孔、圆角、倒角、阵列、抽壳、加厚和尺寸编辑等实现 |
| `src/elem_utils.cpp` | 元素树和选择集辅助函数 |
| `PLAN.md` / `STATUS.md` / `ELEM_TREES.md` | 方案、验证状态、元素树研究 |
| `test/dev_probe.py` | 加载、派发、结果检查探针；使用前审查其会话与许可证处理 |

## 离线构建

在后端项目目录中，参考 `build.cmd devbuild` 将结果输出为 `out/devbuild.dll`，用于避免覆盖正在运行的正式 DLL。项目可通过其支持的构建变量配置 SDK 和编译工具位置；先读脚本，不假定变量名或默认路径。

```powershell
# 在另行取得的后端项目根目录执行，仅编译，不启动 Creo。
cmd /c .\build.cmd devbuild
```

本示例仅适用于提供该构建脚本的项目。`build_and_unlock.cmd` 和旧 `dev_probe.py` 的历史版本包含机器专用路径；不能未经检查直接运行。先使其使用本地明确配置，并移除硬编码许可证位置。

## 加载与验证

加载前确认 DLL 已按所用 SDK 的要求构建、解锁，且未在当前会话映射。旧探针说明中“换应用名避免占用”的建议不能作为安全恢复方案；相同 DLL 路径可能在卸载后仍被映射。

如项目提供兼容的 `dev_probe.py`，先运行 `--help` 查看参数，再在授权测试会话与独立测试模型中使用 `--dll`、`--action`、`--params-file` 等入口。示例特征 id 不能跨模型复用；先创建种子并读取其实际 id。

每个新特征的验证记录至少应覆盖：

- 使用的源码版本、DLL 标识、目标 Creo/SDK 与 action 参数。
- 创建、再生、特征类型和状态结果，必要时包含错误列表。
- 与目标操作对应的几何证据，例如孔位、壁厚、体积变化、实体数量，而非仅成功布尔值。
- 保存路径及需要时的保存后重开验证。

不要复制 SDK 示例源码或头文件到技能包。研究时引用本地已安装 SDK 的相对位置，例如 `protoolkit/protk_appls`，并单独记录借鉴范围和再分发条件。
