# Creo 建模工作区指令示例

仅将本文件中适合当前工作区的规则合并到自己的 `AGENTS.md`，不要覆盖已有指令。

- Creo 任务开始前，确认用户允许的操作、目标模型、单位和输出位置。单位默认毫米。
- 使用匹配的技能：规则特征、曲面、参数修改、排障或 TOOLKIT 开发。
- 工具不可用时明确报告缺少的后端；不要虚构工具调用或成功结果。
- 在用户已有 Creo 会话中工作。需要启动时沿用用户的快捷方式、语言和工作目录；保持单会话，不自动终止服务或关闭会话。
- 原生特征和 STEP 导入实体分别说明。曲面加厚前后检查实体有效性，不能把面组当作闭合实体交付。
- 修改已有零件前，核对目标名称及当前窗口；同名创建或重生成前核实文件副作用并保留备份。
- 成功交付需确认几何完整、实际保存路径及 Creo 中可见；声明未完成的工程验证。
