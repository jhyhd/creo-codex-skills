# 能力与限制

本项目提供五个 Creo 工作流技能及一个独立屏幕观察技能。Creo 部分记录两条建模通道；相关结论来自原始实现源码及本地测试记录，环境主要为 Windows x64、Creo Parametric 11.0.0.0、build123d 0.11.1。未据此验证其他版本、补丁、许可证组合或生产稳定性。本次整理不运行 Creo 集成测试。

## 屏幕观察闭环

`screen-observe-loop` 可在 Windows 桌面独立使用，不需要 Creo、MCP 或第三方 Python 图像库。辅助脚本提供单帧截图和有限时段连续截图；可用于观察 Creo，也可用于其他应用。

截图与理解是两个步骤。脚本将画面写入文件，agent 再通过 `view_image` 等工具读取新帧，判断状态、决定任务范围内的下一步，并在操作后继续观察。仅运行 `watch` 不会自动识别画面、读取文字、控制界面或证明任务完成。

循环需要明确时限、轮次和停止条件。用户要求停止、目标达成、重复无进展或出现需用户决定的状态时，应停止推进。截图可证明某一时刻的界面外观，不能替代 CAD 尺寸、实体有效性或工程验收。运行时截图放在仓库之外，不作为公开示例或发布内容。

## 选择 Creo 建模通道

| 目标 | 通道 | 产物与修改方式 |
|---|---|---|
| 板、轴、盘、法兰、支架等规则零件 | TOOLKIT 原生特征 | Creo 特征树；支持范围内可改内部草图尺寸或按配方重建 |
| 放样、扫掠、扭转等复杂几何 | build123d → STEP → Creo | 导入实体或曲面；外形修改主要回到代码/模板重生成 |
| 现有 STEP/IGES 的查看和继续设计 | 文件导入 | 当前工具按零件导入；装配层级、颜色和多实体组织须实际核对 |
| 自由形体的 ID 概念设计 | 自定义几何及外部建模方法 | 可生成 CAD 几何；整机完整性、运动与制造可用性需单独验证 |

按用户的结果要求选择。无需原生特征树时，不必为使用原生工具而强行将自由形体拆成规则特征。

## 原生特征

原实现不是仅靠 COM 创建所有特征：COM 负责会话和插件通信，另有 C++ TOOLKIT 插件构建元素树。“COM 通道缺少所需特征创建入口”不等于“Creo 无法自动创建原生特征”。

已实现范围包括基准面、拉伸、旋转、孔、圆角、倒角、部分阵列、抽壳、曲面拉伸/旋转、加厚和部分内部草图尺寸修改。本地的一个示例通过，不保证任意参数、拓扑或参考选择都可用。

当前 `draft` 与 `mirror` 返回未实现错误；它们出现在动作路由或说明中，不代表拔模和镜像已可用。配方重建会重新创建特征树，并可能删除旧文件，与就地改尺寸不同，见[工具契约](TOOL-CONTRACT.md)。

## 曲面与导入

build123d 可生成实体、复合体或曲面。只有闭合有效实体才应报告为实体；面组导入成功不等于封闭体积。所需壁厚、开口、连接和实体数应通过剖切或几何检查确认。

原记录没有在所检查的 Creo 11 头文件和现有桥接中找到创建“边界混合”、ISDX 或 Freestyle 的可用路径。因此**本项目不提供这些原生命令的自动化入口**。这不是对所有 PTC 版本、接口或未来能力的官方否定。Gordon、放样等外部曲面可用于构形，但不应无条件称为与原生命令等效。

当前 `gordon` 模板只把每项的前两个点构造成直线。需要样条曲线网时须另写并验证几何代码；向该模板追加点不代表它们会被使用。

## 验收标准

按交付目标检查，而非只检查文件存在：

- 规则零件：创建与再生状态、类型、关键尺寸、实体数、保存后回读。
- 曲面/导入件：有效性、实体或曲面分类、包围尺寸、体积或面积、剖切和导出回读。
- 装配/整机：部件完整性、连接、关节与支撑关系、坐标与落地平面；若干外壳不能代替完整整机。
- 展示：实际 Creo 窗口中的模型、方向与适屏。`shown` 字段或外部渲染不能单独证明用户界面已显示模型。

ID 模型可用于形态评审、测量与后续设计。可行走、可制造或可量产还需传动、电机与内部布置、运动干涉、强度、材料和工艺验证；本技能包不自动完成这些工作。
